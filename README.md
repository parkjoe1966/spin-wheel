# 돌려돌려 룰렛

선택지 개수만큼 칸이 생기는 룰렛 게임. 설치 없이 브라우저에서 돌아가고, 폰 홈 화면에 앱처럼 설치할 수 있습니다.

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 앱 전체 (화면, 룰렛, 음악) |
| `manifest.webmanifest` | 폰에 설치할 때 쓰는 앱 이름·아이콘 정보 |
| `sw.js` | 오프라인에서도 열리게 하는 서비스 워커 |
| `icons/` | 앱 아이콘 |

## 폰 앱으로 쓰려면

앱 설치는 **https 주소**에서만 됩니다. 이 폴더를 통째로 무료 호스팅에 올리세요.

- **Netlify Drop**: https://app.netlify.com/drop 에 폴더를 끌어다 놓으면 주소가 바로 생깁니다.
- **GitHub Pages**: 저장소에 올린 뒤 Settings → Pages에서 켭니다.

주소를 폰에서 연 뒤:

- **안드로이드(Chrome)**: 화면 위의 "앱 설치" 버튼, 또는 메뉴 → 홈 화면에 추가
- **아이폰(Safari)**: 공유 버튼 → 홈 화면에 추가

## 참고

- 저장한 게임은 각 기기의 브라우저에만 보관됩니다. 친구에게는 "게임 코드 복사"로 보내세요.
- 음악과 효과음은 브라우저에서 직접 합성하므로 음원 파일이 없습니다.
- 비상업적 용도로 자유롭게 사용할 수 있습니다.
